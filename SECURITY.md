# Sécurité

Merci de signaler toute vulnérabilité de sécurité de façon responsable. N’ouvrez pas d’issue publique contenant une méthode d’exploitation ou des données sensibles.

Utilisez le signalement privé de vulnérabilité de GitHub dans l’onglet **Security** du dépôt s’il est disponible. Sinon, contactez le propriétaire du dépôt via son profil GitHub pour convenir d’un canal privé. Indiquez les versions concernées, les étapes de reproduction et l’impact possible, sans inclure de secrets réels.

Les identifiants, clés privées, mots de passe, sauvegardes, bases de données et modèles audio propres à une installation ne doivent jamais être ajoutés au dépôt.
