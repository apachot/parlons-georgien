# Code de conduite

Nous voulons que Parlons géorgien reste un espace accueillant pour apprendre et contribuer.

Les participantes et participants s’engagent à communiquer avec respect, à accueillir les points de vue différents, à critiquer les idées sans attaquer les personnes et à aider les autres à progresser. Le harcèlement, les propos discriminatoires, les insultes et la publication d’informations privées sans consentement ne sont pas acceptables.

Les responsables du projet peuvent modifier, masquer ou supprimer les contributions qui ne respectent pas ces règles. Pour signaler un problème, contactez le propriétaire du dépôt via son profil GitHub.
