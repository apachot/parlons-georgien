# Icônes Lucide

Ces SVG proviennent du jeu d’icônes [Lucide](https://lucide.dev/icons/), distribué sous licence ISC. Le texte complet de la licence et les notices d’origine sont conservés dans `LICENSE`.

Les contours ont été adaptés à la couleur prune `#71384d` pour garder le même rendu monochrome dans l’interface. Les icônes sont servies localement, sans dépendance à un CDN.
